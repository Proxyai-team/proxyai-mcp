Each surface completed one separately approved Knowledge Base Refresh test run with a US$2 per-run cap and normal email fee. Report generation and email.send returned success. A previous Weekly Sales Digest run failed because the synthetic bot had no connected store. Non-store recipe success does not prove store-report execution. Refresh/revocation, foreign-account, full pagination and approval/apply branches were not all exercised in these hosted tests.

Scope denial was observed without mutation. Both hosted test surfaces needed explicit read/write scope selection in a fresh OAuth flow; seamless automatic upgrade was not verified. Codex's earlier local tool tests used simulated delivery and a disposable database. Claude Code setup syntax was verified from client help; it was not separately rehearsed end to end.

Run `npm run check` for local package consistency. Run `npm run probe` for current public metadata and unauthenticated challenge checks.
